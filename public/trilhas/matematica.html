Resumo Executivo

Base da trilha de Matemática do index: 13:30–14:30, 1h por dia, 12 fases e 64 semanas.

Visão geral

Esta trilha existe para garantir que matemática seja usada como ferramenta de engenharia, não como estudo abstrato. Todo conceito precisa terminar em código, notebook, benchmark, gráfico, métrica, artigo ou decisão técnica.

O foco principal é programação e desenvolvimento de IA: algoritmos, complexidade, estruturas de dados, embeddings, machine learning, deep learning, transformers, RAG, retrieval, ranking e avaliação de sistemas inteligentes.

Regra central

Todo conceito matemático deve terminar em uma aplicação prática: implementação em Python/Java/notebook, gráfico, benchmark, métrica, algoritmo, explicação no blog ou conexão direta com embeddings, loss, gradiente, attention, retrieval ou avaliação de IA.

Cosine similarity com NumPy

import numpy as np

def cosine_similarity(a: np.ndarray, b: np.ndarray) -> float:
    denom = np.linalg.norm(a) * np.linalg.norm(b)
    if denom == 0:
        return 0.0
    return float(np.dot(a, b) / denom)

v1 = np.array([0.2, 0.5, 0.1])
v2 = np.array([0.1, 0.4, 0.3])
print(cosine_similarity(v1, v2))

Softmax com estabilização numérica

import numpy as np

def softmax(x: np.ndarray, temperature: float = 1.0) -> np.ndarray:
    z = x / temperature
    z = z - np.max(z)  # evita overflow
    exp = np.exp(z)
    return exp / exp.sum()

logits = np.array([2.0, 1.0, 0.1])
print(softmax(logits, temperature=0.7))

Self-attention simplificado em PyTorch

import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)
    return weights @ V, weights

batch, tokens, dim = 1, 4, 8
Q = torch.randn(batch, tokens, dim)
K = torch.randn(batch, tokens, dim)
V = torch.randn(batch, tokens, dim)
out, weights = scaled_dot_product_attention(Q, K, V)
print(out.shape, weights.shape)

Métricas de retrieval: MRR simples

def reciprocal_rank(results: list[str], expected_id: str) -> float:
    for index, item_id in enumerate(results, start=1):
        if item_id == expected_id:
            return 1.0 / index
    return 0.0

queries = [
    (["doc7", "doc3", "doc1"], "doc3"),
    (["doc2", "doc8", "doc9"], "doc9"),
]
mrr = sum(reciprocal_rank(r, expected) for r, expected in queries) / len(queries)
print(mrr)
