# Evidência — sistema de interface inclusivo

## Baseline

O processo crítico atende WCAG 2.2 AA com semântica nativa, teclado, zoom e tecnologia assistiva.

## Prova mínima

- Auditoria automatizada e roteiro humano separados.
- Modal, menu, abas ou notificações com padrão APG justificado.
- Tokens primitivos e semânticos com variantes finitas.
- Testes de comportamento, acessibilidade e regressão visual.
- Matriz mínima de navegador e tecnologia assistiva.

## Governança

Registre versão, breaking changes visuais, exceções, adoção e plano de migração.
