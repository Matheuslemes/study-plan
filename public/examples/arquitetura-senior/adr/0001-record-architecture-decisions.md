# ADR 0001 — Registrar decisões de arquitetura

- Status: aceito
- Data: 2026-07-27

## Contexto
Decisões estruturais eram tomadas em conversas e se perdiam quando as pessoas
saíam do time. O "porquê" desaparecia e erros já descartados voltavam.

## Decisão
Registrar toda decisão arquiteturalmente significativa como um ADR versionado no
repositório, no formato contexto / decisão / consequências / status.

## Consequências
- Positivo: histórico rastreável, onboarding mais rápido, revisão consciente.
- Negativo: exige disciplina de escrita a cada decisão relevante.
- Neutro: ADRs antigos podem ser marcados como "superados por" outro ADR.
